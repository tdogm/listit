# ListIT 🛍️

ListIT is a multi-platform marketplace app that allows users to create a single listing and post it across multiple selling platforms like Shopify, eBay, and more.

## 🚀 Features

- Create and manage product listings
- Upload images and descriptions
- Post listings to external platforms (Shopify integration in progress)
- User authentication (Supabase)
- Dashboard for managing listings

## 🛠️ Tech Stack

- Frontend: Next.js (App Router)
- Backend: Next.js API Routes
- Database & Auth: Supabase
- Deployment: Vercel (planned)
- Integrations: Shopify API (in progress)
